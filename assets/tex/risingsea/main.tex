\mtexe{1.2.A}
\begin{proof}
	The two notions can be identified. Indeed, given a group $G$ in the usual sense, define a category with a single object $X$, and for each $g \in G$, define a morphism $f_g : X \to X$. Further, for two morphisms $f_g,f_h$, define composition by $f_g \circ f_h = f_{gh}$. This gives a 1-object groupoid, since each morphism is an isomorphism: the morphism $f_g$ has inverse $f_{g^{-1}}$.
	
	Conversely, given a 1-object groupoid, the set of morphisms on that one object forms a group. \\
	
	On the other hand, there are clearly groupoids that aren't groups, e.g. a category with two objects and only the identity morphisms on those objects.
\end{proof}

\mtexe{1.2.B}
\begin{proof}
	The identity morphism is invertible, with itself as left- and right-inverse. The composition of two invertible morphisms is again invertible, since $(f \circ g) \circ (g^{-1} \circ f^{-1}) = \id$. Finally, the inverse of an invertible morphism is invertible. So, the set of invertible morphisms forms a group under composition. \\
	
	Given a set $X$, the automorphisms of $X$ in the category of sets is the set of bijections $f : X \to X$, i.e. the automorphism group is $S_X$, the symmetric group on $X$. The automorphisms of a vector space in $Vec_k$ are the automorphisms in the usual sense in linear algebra. \\
	
	Finally, if $A$ and $B$ are isomorphic objects, with an isomorphism $f : A \to B$, then for an automorphism $\phi : A \to A$, the morphism $f \circ \phi \circ f^{-1}$ is an automorphism of $B$, with inverse $f \circ \phi^{-1} \circ f^{-1}$. So, this association gives an isomorphism of automorphism groups.
\end{proof}

\mtexe{1.3.A}
\begin{proof}
	Let $A,B$ both be initial objects in some category. Then, since $A$ is initial, there is a morphism $f : A \to B$, and since $B$ is initial, there is a morphism $g : B \to A$. Then $\id_A$ and $g \circ f$ are both morphisms $A \to A$, but since $A$ is initial, there is a unique such morphism, so $g \circ f = \id_A$. Similarly, $f \circ g = \id_B$. So, $f$ and $g$ are isomorphisms. Further, this isomorphism is unique since any isomorphism $A \to B$ is firstly a morphism, and there is a unique such morphism since $A$ is initial.
	
	The case of final objects is identical. In fact, this proof already shows it by noting that an object is final in a category if and only if it is initial in the opposite category.
\end{proof}

\mtexe{1.3.B}
\begin{proof}[Solution]
	The initial object in $Sets$ is the empty set, since there is a unique map from the empty set to any other set. The final object in $Sets$ is any set with a single element, since there is a unique map from any set to this set. Note that specifying which single-element set is irrelevant, since any two such sets are uniquely isomorphic as sets. \\
	
	The initial object in $Rings$ is $\ZZ$ (recall we are only considering commutative rings with unity and morphisms that preserve unities), since there is a unique morphism given by mapping $1$ to $1 \in R$ for a given ring $R$. The final object is the zero ring. \\
	
	$Top$ is the ``same'' as set: the initial object is the empty space and the final object is a single-point space, since there is a unique continuous map in each case. \\
	
	Given a set $S$, the poset category of subsets of $S$ has $\emptyset$ as an initial object since it is a subset of each other subset of $S$, and it has $S$ as a final object. If $S$ is a topological space and we consider the poset category of open subsets of $S$, the initial and final objects are the same.
\end{proof}

\mtexe{1.3.D}
\begin{proof}
	First, note that $A \to S^{-1}A$ has the property that all elements of $S$ are mapped to invertible elements, since for $s \in S$, the image is $s/1$, which has inverse $1/s \in S^{-1}A$. Now we want to see that it is initial with respect to this property. So, let $f : A \to B$ be a morphism with each element of $S$ mapping to an invertible element of $B$. Then, we'd like to define a factorization through $S^{-1}A$. Define:
	\[ g(a/s) = f(a)f(s)^{-1} \]
	First, note that this definition makes sense, since for each $s \in S$, $f(s)$ is invertible and so $f(s)^{-1}$ exists. Second, we want to see that it is well-defined. So, suppose $a/s = b/t$, so that there ihs some $r \in S$ with $r(ta-sb) = 0$. Then,
	\[ 0 = f(r(ta-sb)) = f(r)(f(t)f(a)-f(s)f(b)) \]
	Since $f(r)$ is invertible, we can cancel it, and then multiplying by the inverses of $f(t)$ and $f(s)$ gives:
	\[ f(a)f(s)^{-1} = f(b)f(t)^{-1} \]
	so that $g$ is well-defined. Finally, we want to see it is a ring homomorphism. First, we have $g(1/1) = f(1)f(1)^{-1} = 1$. Second, if $a/s,b/t \in S^{-1}A$, then
	\[ g(a/s+b/t) = g((at+bs)/(st)) = f(at+bs)f(st)^{-1} = f(a)f(s)^{-1}+f(b)f(t)^{-1} = g(a/s)+g(b/t) \]
	and
	\[ g((a/s)(b/t)) = g((ab)/(st)) = f(ab)f(st)^{-1} = f(a)f(b)f(s)^{-1}f(t)^{-1} = g(a/s)g(b/t) \]
	as desired. Thus $g$ is a ring homomorphism. Penultimately, we show it factors $f$. Let $\iota : A \to S^{-1}A$ be the canonical map. Then, for $a \in A$,
	\[ g(\iota(a)) = g(a/1) = f(a)f(1)^{-1} = f(a) \]
	so that $f = g \circ \iota$ as desired. To finally finish, we need to see that $g$ is unique. So, suppose we have another ring homomorphism $h : S^{-1}A \to B$ with $f = h \circ \iota$. Then, let $a/s \in S^{-1}A$. We have
	\[ h(a/s) = h((a/1)(1/s)) = h(a/1)h(1/s) = h(a/1)h(s/1)^{-1} = h(\iota(a))h(\iota(s))^{-1} = f(a)f(s)^{-1} = g(a/s) \]
	so that $h = g$. This completes the proof that $S^{-1}A$ is initial among such rings. \\
	
	We address the ``furthermore.'' Let $M$ be an $S^{-1}A$-module. Then, it is also an $A$-module via $a \cdot m = (a/1) \cdot m$ for $a \in A$ and $m \in M$ (restriction of scalars). For $s \in S$, multiplication by $s$ is an isomorphism of $M$ since it has inverse given by multiplication by $1/s$.
	
	Conversely, suppose $M$ is an $A$ module such that multiplication by $s$ is an automorphism of $M$ for all $s \in S$. For $x \in A$, let $\varphi(x) : M \to M$ denote multiplication by $x$, and let $R' = \varphi(A)$ be the image of $A$ in the endomorphism ring of $M$. Then $R'$ is a commutative ring with unity, and an application of Zorn's Lemma gives a maximal subring $R$ of the endomorphism ring of $M$ containing $R'$. Then, $\varphi : A \to R$ and each element of $S$ maps to an invertible element of $R$, so this factors as a map from $S^{-1}A$, i.e. we get a map from $S^{-1}A$ into the endomorphism ring of $M$, i.e. $M$ is an $S^{-1}A$-module.
\end{proof}
Note: This last part of the proof could be simplified if we prove that the universal property doesn't require the target ring to be commutative, because then we can directly note that an $A$-module $M$ with image of each $s \in S$ being an isomorphism is precisely a map from $A$ into the endomorphism ring of $M$ with each element of $S$ mapping to a unit.

\mtexe{1.3.F}
\begin{proof}
	Parts (a) and (b) are both subsumed under showing that localization commutes with arbitrary direct sums. For this, it's useful to give direct sums a universal property. We claim (and show after this proof) that the direct sum of $A$-modules $\{M_j\}$ is an $A$-module $P$ along with maps $P \to M_j$ that is initial with respect to have maps into each $M_j$.
	
	Now, given this property, define $P = \bigoplus_j M_j$ and $Q = \bigoplus_j S^{-1}M_j$. We wish to show that $Q = S^{-1}P$. To do this, we show that $Q$ has the universal property of being the localization of $P$. First, we need a map $P \to Q$. To find it, note that for each $j$ we have maps $\ell_j : M_j \to S^{-1}M_j$ via localization and $g_j : S^{-1}M_j \to Q$ via the direct sum. Hence, since $P$ is the direct sum, we have a unique map $f : P \to Q$ such that $f \circ f_j = g_j \circ \ell_j$ for each $j$, i.e. we have commutative diagrams:
	\[ \begin{tikzcd} M_j \arrow{r}{\ell_j} \arrow{d}{f_j} & S^{-1}M_j \arrow{d}{g_j} \\ P \arrow{r}{f} & Q \end{tikzcd} \]
	
	Finally, we show that $f : P \to Q$ is the localization map. To prove this, let $N$ be an $S^{-1}A$-module, and let $\alpha : P \to N$ be a morphism. Then, for each $j$, we have the composition map $\alpha \circ f_j$, and by the universal property of the localization, we thus get that each of these factors through a map $\alpha_j : S^{-1}M_j \to N$. I.e. the diagram extends
	\[ \begin{tikzcd} M_j \arrow{r}{\ell_j} \arrow{d}{f_j} & S^{-1}M_j \arrow{d}{g_j} \arrow{ddr}{\alpha_j} \\ P \arrow{r}{f} \arrow{drr}{\alpha} & Q \arrow[dashed]{dr}{\beta} \\ & & N \end{tikzcd} \]
	By the universal property of $Q$, the dashed arrow exists and makes the diagram commute. We finally wish to show that $\alpha = \beta \circ f$. Fix a $j$, and note that
	\[ (\beta \circ f) \circ f_j = \beta \circ (g_j \circ \ell_j) = \alpha_j \circ \ell_j = \alpha \circ f_j \]
	So, the two maps agree when composed by $f_j$ for each $j$, and by the uniqueness part of the property of direct sums, we get that $\beta \circ f = \alpha$.
	
	Finally, we wish to show $\beta$ is unique. Suppose $\gamma : Q \to N$ satisfies $\gamma \circ f = \alpha$. Then, for each $j$ we have
	\[ \gamma \circ g_j \circ \ell_j = \gamma \circ f \circ f_j = \beta \circ f \circ f_j = \beta \circ g_j \circ \ell_j \]
	By the universal property of $\ell_j$, for each $j$, we get $\gamma \circ g_j = \beta \circ g_j$. Then, by the universal property of $Q$, we have that $\gamma = \beta$. This proves uniqueness. In other words, $(Q,f)$ has the property that for any $S$-invertible map $P \to N$ factors uniquely through $f$, so that $Q = S^{-1}P$. \\
	
	For the counterexample, we consider the suggestion, and let $A = \ZZ$ and for each $n \in \NN$ let $M_n = \ZZ$ as well. Let $S = \ZZ \setminus \{0\}$, so that $S^{-1}M_n = \QQ$ for each $n$. Thus,
	\[ (1, 1/2, 1/3, 1/4, \ldots) \in \prod_{n=1}^\infty \QQ = Q \]
	On the other hand, our explicit description of $S^{-1}P$ shows that for each element of $S^{-1}P$, there is an element of $S$ that multiplies it into (the image of) $P$. But for this element, there is no multiple of it that consists entirely of integers, since the denominators get arbitrarily large. So, this element of $Q$ isn't in $S^{-1}P$ and so they aren't equal.
\end{proof}

\mtexe{1.3.H}
\begin{proof}
	To see that it is a functor, note that it gives a way to map objects to objects, but we also need to map morphisms to morphisms. So, let $f : M \to L$ be a morphism of $A$-modules. Then, we can define $f \otimes N : M \otimes N \to L \otimes N$ via $m \otimes n \mapsto f(m) \otimes n$ and extending linearly. Now, we have $(\id_M \otimes N)(m \otimes n) = \id_M(m) \otimes n = m \otimes n$ for all $m,n$, so that the identity is mapped to the identity. Second, if $f : M \to L$ and $g : L \to K$, then for all $m \in M$, $n \in N$:
	\begin{align*}
	((g \circ f) \otimes N)(m \otimes n)
		&= (g \circ f)(m) \otimes n \\
		&= g(f(m)) \otimes n \\
		&= (g \otimes N)(f(m) \otimes n) \\
		&= (g \otimes N)((f \otimes N)(m \otimes n)) \\
		&= ((g \otimes N) \circ (f \otimes N))(m \otimes n)
	\end{align*}
	so that $\otimes N$ distributes over compositions. This shows that $\otimes N$ is a functor. \\
	
	Now, let $M \xrightarrow{f} L \xrightarrow{g} K \to 0$ is exact. We wish to show that $g \otimes N$ surjects and that $\ker(g \otimes N) = \im(f \otimes N)$. For the first, it suffices for the image to contain each simple tensor, but this is immediate: for $k \in K$ there is $\ell \in L$ with $g(\ell) = k$, so that $(g \otimes N)(\ell \otimes n) = k \otimes n$ for any $n \in N$.
	
	For the second, first note that $((g \otimes N) \circ (f \otimes N)) = (g \circ f) \otimes N = 0 \otimes N = 0$ is the zero map. So, we have that the image is contained in the kernel; we need the reverse. For this, we lift to the free modules lying over the tensor products and pick generators there. We lift to a map $\hat{g} : A[L \times N] \to A[K \times N]$ via $(\ell,n) \mapsto (g(\ell), n)$, and note that $(g \otimes N) \circ \pi_L = \pi_K \circ \hat{g}$, where $\pi_x$ denotes the projection $A[x \times N] \to x \otimes N$. Since $\pi_L$ is surjective, we have
	\[ \ker(g \otimes N) = \pi_L(\ker((g \otimes N) \circ \pi_L)) = \pi_L(\ker(\pi_K \circ \hat{g})) = \pi_L(\hat{g}^{-1}(\ker(\pi_K))) \]
	Now, $\ker(\pi_K)$ is generated by all of the tensor relations:
	\[ (k+k',n)-(k,n)-(k',n), (k,n+n')-(k,n)-(k,n'), a(k,n)-(ak,n), a(k,n)-(k,an) \]
	So, the preimage under $\hat{g}$ is generated by the preimage of these generators and the kernel of $\hat{g}$ itself. The preimages are precisely the tensor relations of $L \otimes N$ since $g$ is surjective, i.e. all of these relations:
	\[ (\ell+\ell',n)-(\ell,n)-(\ell',n), (\ell,n+n')-(\ell,n)-(\ell,n'), a(\ell,n)-(a\ell,n), a(\ell,n)-(\ell,an) \]
	Further, $\hat{g}$ is a map between free modules, so the kernel is generated by elements of the form $x-x'$ with $x,x'$ among the basis and $\hat{g}(x)=\hat{g}(x')$. I.e. for elements $\ell,\ell' \in L$ and $n \in N$ with $g(\ell)=g(\ell')$, the kernel is generated by $(\ell,n)-(\ell',n)$.
	
	Finally, we map all of these generators back under $\pi_L$. The tensor relations all map to zero in $L \otimes N$ essentially by definition. So, $\ker(g \otimes N)$ is generated by $\ell \otimes n - \ell' \otimes n$ for $g(\ell)=g(\ell')$. But then $g(\ell-\ell') = 0$, so $\ell-\ell' \in \ker(g) = \im(f)$ by exactness, so that there is some $m \in M$ with $f(m) = \ell-\ell'$. But then,
	\[ (f \otimes N)(m \otimes n) = f(m) \otimes n = (\ell-\ell') \otimes n = \ell \otimes n - \ell' \otimes n \]
	is in the image of $(f \otimes N)$.
\end{proof}

		&= g_i((a\ell+bm) \otimes n) \\
		&= ag_i(\ell \otimes n)+bg_i(m \otimes n) \\
		&= a\varphi_{\ell,i}(n)+b\varphi_{m,i}(n) \\
		&= (a\varphi_\ell+b\varphi_m)(f_i(n)) \\
		&= ((a\varphi_\ell+b\varphi_m) \circ f_i)(n)
	\end{align*}
	So, $a\varphi_\ell+b\varphi_m : P \to Q$ satisfies the unique property of $\varphi_{a\ell+bm}$, i.e. they must be equal. This gives linearity in the first coordinate:
	\[ \varphi(a\ell+bm,p) = \varphi_{a\ell+bm}(p) = (a\varphi_\ell+b\varphi_m)(p) = a\varphi_\ell(p)+b\varphi_m(p) = a\varphi(\ell,p)+b\varphi(m,p) \]

	\[ (h \circ (\id_M \otimes f_i))(m \otimes n) = h(m \otimes f_i(n)) = \varphi(m, f_i(n)) = \varphi_m(f_i(n)) = \varphi_{m,i}(n) = g_i(m \otimes n) \]
	as claimed.

\end{proof}

\mtexe{1.4.F}
\begin{proof}
	Let us establish some notation. Let $A$ be a ring. For $a \in A$, let $m_a : A[x] \to A[x]$ denote the map that is the identity on $A$ with $x \mapsto ax$. Let $\alpha : A \to A[x]$ be the natural inclusion (as constants). We can see immediately that $m_a \circ \alpha = \alpha$ and that $m_a \circ m_{a'} = m_{aa'}$. Also recall that maps out of $A[x]$ are (freely, uniquely) determined by maps out of $A$ and a specified value of $x$.

	Recall that if $A$ is a ring and $S \subseteq A$ is a multiplicative subset, then $S^{-1}A$ is defined by the universal property of being initial among $A$-algebras inverting $S$. Precisely, there is a structure map $i : A \to S^{-1}A$ such that $i(s)$ is a unit for every $s \in S$ and if $f : A \to B$ is a ring map with $f(s)$ a unit for every $s \in S$, then there exists a unique map $g : S^{-1}A \to B$ with $f = g \circ i$. It exists by a direct construction.
	
	We will show that $S^{-1}A$ is a filtered colimit of a specific diagram in the category of $A$-algebras. Let us now construct that diagram. For each $s \in S$, consider the $A$-algebra $A_s = A[x]/(sx-1)$ equipped with the quotient map $q_s : A[x] \to A_s$, with structure map $q_s \circ \alpha : A \to A_s$. Then, if $a \in A$ and $s \in S$ are such that $as \in S$, then define $\mu_{a,s}$ as the unique map making the following diagram commute:
	\[ \begin{tikzcd} A[x] \arrow[d,"q_s"] \arrow[r,"m_a"] & A[x] \arrow[d,"q_{as}"] \\ A_s \arrow[r,"\mu_{a,s}"] & A_{as} \end{tikzcd} \]
	This exists since top composition kills $sx-1$, as $q_{as}(m_a(sx-1)) = q_{as}(s(ax)-1) = 0$. Note that this collection of objects and morphisms is a diagram since $\mu_{1,s} = \id_{A_s}$ and $\mu_{a',as} \circ \mu_{a,s} = \mu_{aa',s}$. These are also maps of $A$-algebras, since
	\[ \mu_{a,s} \circ (q_s \circ \alpha) = q_{as} \circ m_a \circ \alpha = q_{as} \circ \alpha \]
	i.e. the morphisms commute with the structure maps.
	
	To show that $S^{-1}A$ is the colimit of this diagram, we begin by establishing it as a cone under the diagram. For $z \in S^{-1}A$, we can define a map $e_z : A[x] \to S^{-1}A$ so that $e_z \circ \alpha = i$ and $e_z(x) = z$. Note that the first condition makes this a map of $A$-algebras, and this evaluation map satisfies $e_z \circ m_a = e_{i(a)z}$ (scaling the input). Then, for $s \in S$, $i(s)$ is invertible and $e_{i(s)^{-1}}(sx-1) = i(s)i(s)^{-1}-i(1) = 0$, so it factors through $q_s$, i.e. there exists $i_s : A_s \to S^{-1}A$ with $e_{i(s)^{-1}} = i_s \circ q_s$. The collection of maps $i_s$ forms a cone under the diagram, since
	\begin{align*}
	i_{as} \circ \mu_{a,s} \circ q_s
		&= i_{as} \circ q_{as} \circ m_a \\
		&= e_{i(as)^{-1}} \circ m_a \\
		&= e_{i(a)i(as)^{-1}} \\
		&= e_{i(s)^{-1}} \\
		&= i_s \circ q_s
	\end{align*}
	and the surjectivity (epi) of $q_s$ implies $i_{as} \circ \mu_{a,s} = i_s$ as desired.
	
	Lastly, we'd like to see that it is universal. Namely, let $B$ be an $A$-algebra, i.e. a ring with a map $f : A \to B$, along with $A$-algebra morphisms $f_s : A_s \to B$ such that $f_{as} \circ \mu_{a,s} = f_s$ whenever $a \in A$ and $s,as \in S$. Since these are all $A$-algebra morphisms, we get additional commutation relations, namely that $f = f_s \circ (q_s \circ \alpha)$ for any $s \in S$. From this, note that for any $s \in S$, we have
	\[ f(s)f_s(q_s(x)) = f_s(q_s(\alpha(s)))f_s(q_s(x)) = (f_s \circ q_s)(sx) = (f_s \circ q_s)(1) = 1 \]
	so that $f(s)$ is a unit. Thus, we get a unique morphism $g : S^{-1}A \to B$ with $f = g \circ i$. I'd like to show that this factors each $f_s$, i.e. that $f_s = g \circ i_s$. For this, it suffices to show that $f_s \circ q_s = g \circ i_s \circ q_s$ since $q_s$ is epic, and since these are maps on $A[x]$, it suffices to show that they agree after precomposition with $\alpha$ and agree on $x$. For the first of these, note that
	\begin{align*}
	g \circ i_s \circ q_s \circ \alpha
		&= g \circ e_{i(s)^{-1}} \circ \alpha \\
		&= g \circ i \\
		&= f \\
		&= f_s \circ q_s \circ \alpha
	\end{align*}
	as desired. For the second,
	\begin{align*}
	(g \circ i_s \circ q_s)(x)f(s)
		&= g(e_{i(s)^{-1}}(x)i(s)) \\
		&= g(i(s)^{-1}i(s)) \\
		&= g(1) = 1
	\end{align*}
	But we also argued that $(f_s \circ q_s)(x)f(s) = 1$ above, so equating the two and cancelling $f(s)$ gives the agreement on $x$. Thus $f_s = g \circ i_s$ as desired. Finally, we'd like to show that $g$ uniquely factors these maps. So, suppose $g' : S^{-1}A \to B$ is such that $f_s = g' \circ i_s$ for all $s \in S$. Then, choosing any $s \in S$:
	\[ g' \circ i = g' \circ e_{i(s)^{-1}} \circ \alpha = g' \circ i_s \circ q_s \circ \alpha = f_s \circ q_s \circ \alpha = f \]
	But $g$ was the unique map with $g \circ i = f$, so we get that $g' = g$ and we are done. \\
	
	Note that we never make reference to any properties of $A$ in this proof, nor do we use the notion of a filtered colimit. However, it may be useful to point out that this is actually a filtered colimit. Indeed, for $r,s \in S$, we have $rs \in S$, and so we get arrows $\mu_{r,s} : A_s \to A_{rs}$ and $\mu_{s,r} : A_r \to A_{rs}$ in our diagram. Second, suppose we have two arrows $\mu_{a,s},\mu_{b,s} : A_s \to A_{as}$ (in particular, $bs = as$, which is possible for $b \neq a$ if $A$ is not a domain). Then, by assumption, $as = bs \in S$, and so $abs^2 \in S$ by multiplicativity. But then, since $m_{as} \circ m_a = m_{bs} \circ m_a = m_{abs} = m_{as} \circ m_b$, we get that $\mu_{as,as} \circ \mu_{a,s} = \mu_{as,as} \circ \mu_{b,s}$. I.e. we can further compose by $\mu_{as,as}$ to make the two distinct arrows equal.
\end{proof}

	Since $f$ and $g$ agree on simple tensors and are maps of modules, they agree everywhere, i.e. $f = g$ as claimed.

	\[ F(am+a'm',n) = \gamma(am+a'm')(n) = (a\gamma(m)+a'\gamma(m'))(n) = a\gamma(m)(n)+a'\gamma(m')(n) = aF(m,n)+a'F(m',n) \]
	and
	\[ F(m,an+a'n') = \gamma(m)(an+a'n') = a\gamma(m)(n)+a'\gamma(m)(n') = aF(m,n)+a'F(m,n') \]
	So, $F$ is bilinear, and so induces a map $f : M \otimes_A N \to P$ with $f(m \otimes n) = F(m,n)$ for all $m \in M$ and $n \in N$. Then,
	\[ \tau_{MP}(f)(m)(n) = f(m \otimes n) = F(m,n) = \gamma(m)(n) \]
	and so $\tau_{MP}(f) = \gamma$, proving surjectivity and completing the proof.
\end{proof}

\begin{proof}

	\[ \tau_{NM}(f)(n) = f(n \otimes 1) \]
	First, let us again show that $\tau_{NM}$ is well-defined, i.e. that $\tau_{NM}(f)$ is a map of $B$-modules between $N$ and $M_B$. For this, suppose $b,b' \in B$ and $n,n' \in N$; then:
	\[ \tau_{NM}(f)(bn+b'n') = f((bn+b'n') \otimes 1) = bf(n \otimes 1)+b'f(n' \otimes 1) = b\tau_{NM}(f)(n)+b'\tau_{NM}(f)(n') \]
	as claimed.
	
	Next, we show it is an injection. Suppose that $\tau_{NM}(f) = \tau_{NM}(g)$. Then, for $n \in N$ and $a \in A$, we have
	\begin{align*}
	f(n \otimes a)
		&= f(a(n \otimes 1)) \\
		&= af(n \otimes 1) \\
		&= a\tau_{NM}(f)(n) \\
		&= a\tau_{NM}(g)(n) \\
		&= ag(n \otimes 1) \\
		&= g(a(n \otimes 1)) \\
		&= g(n \otimes a)
	\end{align*}
	Once again, since $f$ and $g$ agree on simple tensors, we get that $f = g$ everywhere. To address surjectivity, suppose $\gamma \in \Hom_B(N,M_B)$. Define $F : N \times A \to M$ by $F(n,a) = a\gamma(n)$. Then, for $n,n' \in N$, $a,a' \in A$, and $b,b' \in B$, we have
	\[ F(bn+b'n',a) = a\gamma(bn+b'n') = ab\gamma(n)+ab'\gamma(n) = bF(n,a)+b'F(n',a) \]
	and
	\[ F(n,ba+b'a') = (ba+b'a')\gamma(n) = ba\gamma(n)+b'a'\gamma(n) = bF(n,a)+b'F(n,a') \]
	so that $F$ is $B$-bilinear. So, it induces a map $f : N \otimes_B A \to M$ of $B$-modules satisfying $f(n \otimes a) = F(n,a)$ for all $n \in N$ and $a \in A$. In fact, $f$ is also a map of $A$-modules, since it is already additive and:
	\begin{align*}
	f\left(a\sum_i n_i \otimes a_i\right)
		&= f\left(\sum_i n_i \otimes (aa_i)\right) \\
		&= \sum_i f(n_i \otimes (aa_i)) \\
		&= \sum_i F(n_i,aa_i) \\
		&= \sum_i aa_i\gamma(n_i) \\
		&= a\sum_i a_i\gamma(n_i) \\
		&= a\sum_i F(n_i,a_i) \\
		&= a\sum_i f(n_i \otimes a_i) \\
		&= af\left(\sum_i n_i \otimes a_i\right)
	\end{align*}
	Then, for any $n \in N$,
	\[ \tau_{NM}(f)(n) = f(n \otimes 1) = F(n,1) = 1\gamma(n) = \gamma(n) \]
	so that $\gamma = \tau_{NM}(f)$ and $\tau_{NM}$ surjects.
	
	Finally, let us show naturality in each coordinate. First, suppose we have a map of $B$-modules $\varphi : N \to N'$. I claim the following commutes:
	\[ \begin{tikzcd} \Hom_A(N' \otimes_B A,M) \arrow[r,"(\varphi \otimes \id_A)^\ast"] \arrow[d,"\tau_{N'M}"] & \Hom_A(N \otimes_B A,M) \arrow[d,"\tau_{NM}"] \\ \Hom_B(N',M_B) \arrow[r,"\varphi^\ast"] & \Hom_B(N,M_B) \end{tikzcd} \]
	Let $f \in \Hom_A(N' \otimes_B A,M)$ and $n \in N$. Then,
	\begin{align*}
	(\tau_{NM} \circ (\varphi \otimes \id_A)^\ast)(f)(n)
		&= \tau_{NM}((\varphi \otimes \id_A)^\ast(f))(n) \\
		&= \tau_{NM}(f \circ (\varphi \otimes \id_A))(n) \\
		&= (f \circ (\varphi \otimes \id_A))(n \otimes 1) \\
		&= f(\varphi(n) \otimes 1) \\
		&= \tau_{N'M}(f)(\varphi(n)) \\
		&= (\tau_{N'M}(f) \circ \varphi)(n) \\
		&= (\varphi^\ast(\tau_{N'M}(f)))(n) \\
		&= (\varphi^\ast \circ \tau_{N'M})(f)(n)
	\end{align*}
	For the other direction, let $\psi : M \to M'$ be a map of $A$-modules; we will show that
	\[ \begin{tikzcd} \Hom_A(N \otimes_B A,M) \arrow[r,"\psi_\ast"] \arrow[d,\tau_{NM}] & \Hom_A(N \otimes_B A,M') \arrow[d,\tau_{NM'}] \\ \Hom_B(N,M_B) \arrow[r,"\psi_\ast"] & \Hom_B(N,M_B') \end{tikzcd} \]
	Indeed, let $f \in \Hom_A(N \otimes_B A,M)$ and $n \in N$ and note
	\begin{align*}
	(\tau_{NM'} \circ \psi_\ast)(f)(n)
		&= \tau_{NM'}(\psi_\ast(f))(n) \\
		&= \tau_{NM'}(\psi \circ f)(n) \\
		&= (\psi \circ f)(n \otimes 1) \\
		&= \psi(f(n \otimes 1)) \\
		&= \psi(\tau_{NM}(f)(n)) \\
		&= (\psi \circ \tau_{NM}(f))(n) \\
		&= \psi_\ast(\tau_{NM}(f))(n) \\
		&= (\psi_\ast \circ \tau_{NM})(f)(n)
	\end{align*}
	completing the proof.
\end{proof}

\mtexe{1.5.G}
\begin{proof}
	We will define the functor $H$. For a nonempty abelian semigroup $S$ (written additively), $HS$ will be a group with underlying set $(S \times S)/\sim$, where $(a,b) \sim (c,d)$ iff $a+d+x = c+b+x$ for some $x \in S$, with addition defined on classes by $\overline{(a,b)}+\overline{(c,d)} = \overline{(a+c,b+d)}$. We define the groupification map $\pi : S \to HS$ by $\pi(s) = \overline{(s+s,s)}$. Further, for an abelian semigroup morphism $f : S \to S'$, define $Hf : HS \to HS'$ on classes by $Hf(\overline{(a,b)}) = \overline{(f(a),f(b))}$. We need to check many things about these definitions.
	
	To begin, let us show that $\sim$ is an equivalence relation. First, note that $a+b+a=a+b+a$, so $(a,b) \sim (a,b)$, i.e. $\sim$ is reflexive. If $(a,b) \sim (c,d)$, then $a+d+x = c+b+x$ for some $x$, so $c+b+x = a+d+x$, and so $(c,d) \sim (a,b)$, showing $\sim$ is symmetric. Finally, if $(a,b) \sim (c,d)$ and $(c,d) \sim (e,f)$, then $a+d+x = c+b+x$ and $c+f+y = e+d+y$, so
	\[ a+f+(d+x+c+y) = (a+d+x)+(c+f+y) = (c+b+x)+(e+d+y) = e+b+(d+x+c+y) \]
	whence $(a,b) \sim (e,f)$, so $\sim$ is transitive.
	
	Next, we will show that addition on $HS$ doesn't depend on choice of representatives. So, suppose $(a,b) \sim (a',b')$ and $(c,d) \sim (c',d')$, so that $a+b'+x = a'+b+x$ and $c+d'+y = c'+d+y$ for some $x,y \in S$. Then
	\[ a+c+b'+d'+(x+y) = (a+b'+x)+(c+d'+y) = (a'+b+x)+(c'+d+y) = a'+c'+b+d+(x+y) \]
	so that $(a+c,b+d) \sim (a'+c',b'+d')$, showing that addition is well-defined.
	
	Next, let us show that $HS$ is an abelian group under addition. First, addition is clearly associative and commutative:
	\begin{align*}
		\overline{(a,b)}+\overline{(c,d)} = \overline{(a+c,b+d)} = \overline{(c+a,d+b)} = \overline{(c,d)}+\overline{(a,b)} \\
		(\overline{(a,b)}+\overline{(c,d)})+\overline{(e,f)} = \overline{(a+c,b+d)}+\overline{(e,f)} = \overline{((a+c)+e,(b+d)+f)} = \overline{(a+(c+e),b+(d+f))} = \overline{(a,b)}+\overline{(c+e,d+f)} = \overline{(a,b)}+(\overline{(c,d)}+\overline{(e,f)})
	\end{align*}
	Next, since $S$ is nonempty, we can choose $s_0 \in S$ arbitrary. I claim that $(s_0,s_0)$ is the additive identity. Indeed, for $a,b \in S$, we have
	\[ \overline{(a,b)}+\overline{(s_0,s_0)} = \overline{(a+s_0,b+s_0)} = \overline{(a,b)} \]
	where the final equality is a consequence of $(a+s_0)+b+x = a+(b+s_0)+x$ (for any $x$). Finally, since $(a+b)+s_0+x = s_0+(b+a)+x$ (again for any $x$), we get $(a+b,a+b) \sim (s_0,s_0)$, and so
	\[ \overline{(a,b)}+\overline{(b,a)} = \overline{(a+b,b+a)} = \overline{(s_0,s_0)} \]
	I.e. every element has an additive inverse. This completes the proof that $HS$ is an abelian group.
	
	Next, we show that $\pi$ is a map of abelian semigroups:
	\[ \pi(a)+\pi(b) = \overline{(a+a,a)}+\overline{(b+b,b)} = \overline{(a+a+b+b,a+b)} = \pi(a+b) \]
	since $(a+b)+(a+b) = a+a+b+b$.
	
	We now show that $\pi$ is indeed the groupification morphism. Suppose that $G$ is an abelian group and $f : S \to G$ is an abelian semigroup morphism. Define $f' : HS \to G$ by $f'(\overline{(a,b)}) = f(a)-f(b)$. First, we show this is well-defined. Suppose $(a,b) \sim (c,d)$, so that $a+d+x = c+b+x$ for some $x$. Then,
	\[ f(a)-f(b) = f(a)-f(b)+f(c+b+x)-f(a+d+x) = f(a)-f(b)+f(c)+f(b)+f(x)-f(a)-f(d)-f(x) = f(c)-f(d) \]
	so indeed $f'$ is well-defined. Then,
	\[ (f' \circ \pi)(s) = f'(\pi(s)) = f'(\overline{(s+s,s)}) = f(s+s)-f(s) = f(s)+f(s)-f(s) = f(s) \]
	for any $s \in S$, so that $f' \circ \pi = f$, which is the needed factorization. Furthermore, $f'$ is unique, for if $g \circ \pi = f$, then
	\[ g(\overline{(a,b)}) = g(\overline{(a+a,a)}-\overline{(b+b,b)}) = g(\pi(a))-g(\pi(b)) = f(a)-f(b) = f'(\overline{a,b}) \]
	and so $g = f'$. Note we've used $\overline{(a+a,a)}-\overline{(b+b,b)} = \overline{(a,b)}$, which follows from
	\[ \overline{(b+b,b)}+\overline{(a,b)} = \overline{(a+b+b,b+b)} = \overline{(a+a,a)} \]
	with the final equality coming from $(a+b+b)+a+x = (a+a)+(b+b)+x$ (for any $x$).
	
	This completes the argument that the groupification exists. We'd like to next show that $H$ is a functor. First, note that each $Hf$ for $f : S \to S'$ is well defined. Indeed, if $(a,b) \sim (c,d)$, then $a+d+x = c+b+x$ for some $x$, and $f(a+d+x) = f(c+b+x)$, so $f(a)+f(d)+f(x) = f(c)+f(b)+f(x)$, whence $(f(a),f(b)) \sim (f(c),f(d))$ in $S'$. Second, note that
	\[ H\id_S(\overline{(a,b)}) = \overline{(\id_S(a),\id_S(b))} = \overline{(a,b)} = \id_{HS}(\overline{(a,b)}) \]
	so that $H\id_S = \id_{HS}$. Third, $H$ preserves compositions:
	\begin{align*}
	H(f \circ g)(\overline{(a,b)})
		&= \overline{((f \circ g)(a),(f \circ g)(b))} \\
		&= \overline{(f(g(a)),f(g(b)))} \\
		&= Hf(\overline{(g(a),g(b))}) \\
		&= Hf(Hg(\overline{(a,b)})) \\
		&= (Hf \circ Hg)(\overline{(a,b)})
	\end{align*}
	i.e. $H(f \circ g) = Hf \circ Hg$.
	
	For the rest of the exercise, we show that $H$ is left adjoint to the forgetful functor $F$ from abelian groups to abelian semigroups. Namely, I claim that $\pi^\ast : \Hom(HS,G) \to \Hom(S,FG)$ demonstrates the adjointness. The universal property of groupification is exactly the statement that $\pi^\ast$ is a bijection, so we only need to show naturality in each coordinate. If $\varphi : G \to G'$ is a group homomorphism, then
	\begin{align*}
	\pi^\ast \circ \varphi_\ast)(f)
		&= \pi^\ast(\varphi_\ast(f)) \\
		&= \pi^\ast(\varphi \circ f) \\
		&= (\varphi \circ f) \circ \pi \\
		&= \varphi \circ (f \circ \pi) \\
		&= F\varphi_\ast(f \circ \pi) \\
		&= F\varphi_\ast(\pi^\ast(f)) \\
		&= (F\varphi_\ast \circ \pi^\ast)(f)
	\end{align*}
	is the naturality statement. If $\psi : S \to S'$ is an abelian semigroup morphism, then
	\begin{align*}
	(\pi_S^\ast \circ H\psi^\ast)(f)
		&= \pi_S^\ast(H\psi^\ast(f)) \\
		&= \pi_S^\ast(f \circ H\psi) \\
		&= (f \circ H\psi) \circ \pi_S \\
		&= f \circ (H\psi \circ \pi_S) \\
		&= f \circ \pi_{S'} \circ \psi \\
		&= \psi^\ast(f \circ \pi_{S'}) \\
		&= \psi^\ast(\pi_{S'}^\ast(f))
		&= (\psi^\ast \circ \pi_{S'}^\ast)(f)
	\end{align*}
	is the other naturality. This completes the argument, establishing the adjointness.
\end{proof}

	\[ \frac{f(e_i)}s = \frac{\left(\prod_{j \neq i}s_j\right)n_i}{\prod_j s_j} = \frac{n_i}{s_i} = g(e_i) \]
	Thus, in the diagram above, the latter two vertical arrows are isomorphisms. This implies that the first one is also by a diagram chase. Abstracting it out, I claim that if $\beta,\gamma$ are isomorphisms in the following diagram with exact rows:
	\[ \begin{tikzcd} 0 \arrow[r] & X \arrow[r,"f"] \arrow[d,"\alpha"] & Y \arrow[r,"g"] \arrow[d,"\beta"] & Z \arrow[d,"\gamma"] \\ 0 \arrow[r] & X' \arrow[r,"f'"] & Y' \arrow[r,"g'"] & Z' \end{tikzcd} \]
	then so is $\alpha$. First, note:
	\[ g \circ \beta^{-1} \circ f' = \gamma^{-1} \circ \gamma \circ g \circ \beta^{-1} \circ f' = \gamma^{-1} \circ g' \circ \beta \circ \beta^{-1} \circ f' = \gamma^{-1} \circ g' \circ f' = 0 \]
	by exactness of the bottom row. In particular, $\beta^{-1} \circ f'$ factors through $\ker(g) = f$, i.e. we get a unique map $h : X' \to X$ so that $f \circ h = \beta^{-1} \circ f'$. Then
	\[ f \circ h \circ \alpha = \beta^{-1} \circ f' \circ \alpha = \beta^{-1} \circ \beta \circ f = f \]
	so $h \circ \alpha = \id_X$ because $f$ is a monomorphism. Also,
	\[ f' \circ \alpha \circ h = \beta \circ f \circ h = \beta \circ \beta^{-1} \circ f' = f' \]
	and so $\alpha \circ h = \id_{X'}$ since $f'$ is a monomorphism. This completes the proof by exhibiting $h$ as the inverse of $\alpha$.
\end{proof}

	Suppose $F$ is right-exact and we have a cochain complex $C^i \xrightarrow{d^i} C^{i+1}$ for each $i$. Then
	\[ C^i \xrightarrow{d^i} C^{i+1} \to \coker(d^i) \to 0 \]

	\[ FC^i xrightarrow{Fd^i} FC^{i+1} \to F\coker(d^i) \to 0 \]
	is also exact, giving $F\coker(d^i) = \coker(Fd^i)$. Then, applying $F$ to the standard exact sequence
	\[ 0 \to \im(d^i) \to C^{i+1} \to \coker(d^i) \to 0 \]
	gives the exact sequence
	\[ F\im(d^i) \to FC^{i+1} \to F\coker(d^i) \to 0 \]
	Hence the composition of the first two is zero, and so the first arrow factors through the kernel of the second. Combined with the above isomorphism, we get $F\im(d^i) \to \im(Fd^i)$. Finally, applying $F$ to
	\[ 0 \to H^i(C^\bullet) \to \coker(d^{i-1}) \to \im(d^{i-1}) \to 0 \]
	gives that
	\[ FH^i(C^\bullet) \to F\coker(d^{i-1}) \to F\im(d^i) \to 0 \]
	is exact. Hence, the composition
	\[ FH^i(C^\bullet) \to F\coker(d^{i-1}) \xrightarrow{\cong} \coker(Fd^{i-1}) \to F\im(d^i) \to \im(Fd^i) \]
	is zero, and so the first arrow factors uniquely through the kernel of $\coker(Fd^{i-1}) \to \im(Fd^i)$, which is $H^i(FC^\bullet)$, i.e. we get the desired map $\alpha : FH^i(C^\bullet) \to H^i(FC^\bullet)$. \\

	\[ 0 \to \ker(d^i) \to C^i \xrightarrow{d^i} C^{i+1} \]
	gives the exactness of
	\[ 0 \to F\ker(d^i) \to FC^i \xrightarrow{Fd^i} FC^{i+1} \]
	so that $F\ker(d^i) = \ker(Fd^i)$. Next, applying $F$ to the exact sequence
	\[ 0 \to \ker(d^i) \to C^i \to \im(C^i) \to 0 \]
	gives the exact sequence
	\[ 0 \to F\ker(d^i) \to FC^i \to F\im(d^i) \]
	Thus this composition is zero so the latter map factors through the cokernel of the first. Combined with the above isomorphism, this gives a map $\im(Fd^i) \to F\im(d^i)$. Finally, the exactness of
	\[ 0 \to \im(d^{i-1}) \to \ker(d^i) \to H^i(C^\bullet) \to 0 \]
	gives that
	\[ 0 \to F\im(d^{i-1}) \to F\ker(d^i) \to FH^i(C^\bullet) \]
	is exact. Thus,
	\[ \im(Fd^{i-1}) \to F\im(d^{i-1}) \to F\ker(d^i) \xrightarrow{\cong} \ker(Fd^i) \to FH^i(C^\bullet) \]
	is zero and so the last arrow factors through the cokernel of $\im(Fd^{i-1} \to \ker(Fd^i)$, which is $H^i(FC^\bullet)$, i.e. we get a map $\beta : H^i(FC^\bullet) \to FH^i(C^\bullet)$ as claimed. \\

To show that $\alpha \circ \beta$ is the identity on $H^i(FC^\bullet), it suffices to show this after precomposition by the epimorphism $\ker(Fd^i) \to H^i(FC^\bullet)$ and postcomposition by the monomorphism $H^i(FC^\bullet) \to \coker(Fd^{i-1})$. So, we're studying the composition
	\[ \ker(Fd^i) \to FH^i(C^\bullet) \to \coker(Fd^{i-1}) \]
	By using the kernel and cokernel isomorphisms established above, this is the same as $F(\ker(d^i) \to \coker(d^{i-1})) = (H^i(FC^\bullet) \to \coker(Fd^{i-1})) \circ (\ker(Fd^i) \to H^i(FC^\bullet))$, as needed. To show that $\beta \circ \alpha$ is the identity, note first that $q : F\ker(d^i) \to FH^i(C^\bullet)$ is epic by the exactness of $F$, and similarly $g : FH^i(C^\bullet) \to F\coker(d^{i-1})$ is monic. Thus,
	\[ g \circ (\beta \circ \alpha) \circ q = g' \circ \alpha \circ \beta \circ \alpha \circ \beta \circ q' = g' \circ \alpha \circ \beta \circ q' = g \circ q \]
	which completes the argument.
\end{proof}

\mtexe{1.6.J}
\begin{proof}
	Let $\scI,\scJ$ be index categories, and consider the product category $\scI \times \scJ$ with objects given by pairs of objects $(i,j)$ for $i$ an object of $\scI$ and $j$ an object of $\scJ$, morphisms $(f,g)$ with $f : i \to i'$ a map in $\scI$ and $g : j \to j'$ a map in $\scJ$, and composition done coordinatewise. Suppose we have a functor $F : \scI \times \scJ \to \scC$. Then, for each object $i \in \scI$, we get a functor $F_i : \scJ \to \scC$ given by $F_i(j) = F(i,j)$ and $F_i(g) = F(\id_i,g)$. Suppose that each $F_i$ has a limit $\lim F_i \in \scC$ with projection maps $\pi_{i,j} : \lim F_i \to F_i(j)$ for each $j \in \scJ$. Then, we can associate to each object $i \in \scI$ the object $G(i) = \lim F_i$. Further, for a map $f : i \to i'$ in $\scI$, consider the maps $F(f,\id_j) \circ \pi_{i,j} : \lim F_i \to F(i',j)$. Then, if $g : j \to j'$ is any map in $\scJ$, we have
	\[ F_{i'}(g) \circ F(f,\id_j) \circ \pi_{i,j} = F(\id_{i'},g) \circ F(f,\id_j) \circ \pi_{i,j} = F(f,g) \circ \pi_{i,j} = F(f,\id_{j'}) \circ F(\id_i,g) \circ \pi_{i,j} = F(f,\id_{j'}) \circ \pi_{i,j'} \]
	which shows that the collection of maps is a cone over $F_{i'}$. Thus, we get a unique map $G(f) : \lim F_i \to \lim F_{i'}$ such that $F(f,\id_j) \circ \pi_{i,j} = \pi_{i',j} \circ G(f)$ for each $j$. I claim that $G : \scI \to \scC$ is a functor. Note that
	\[ F(\id_i,\id_j) \circ \pi_{i,j} = \pi_{i,j} \circ \id_{\lim F_i} \]
	which shows that $G(\id_i) = \id_{G(i)}$ by uniqueness. Also, given $f : i \to i'$ and $f' : i' \to i''$ in $\scI$, we have
	\[ F(f' \circ f,\id_j) \circ \pi_{i,j} = F(f',\id_j) \circ F(f,\id_j) \circ \pi_{i,j} = F(f',\id_j) \circ \pi_{i',j} \circ G(f) = \pi_{i'',j} \circ G(f') \circ G(f) \]
	which shows that $G(f' \circ f) = G(f') \circ G(f)$ as desired.
	
	Finally, the setup is complete, and I argue that $\lim G = \lim F$. That is, $F$ has a limit if and only if $G$ does, and any limit for one is a limit for the other (in the sense of objects: the morphisms will be explained below). Note that this essentially says we can compute limits ``stepwise,'' computing the limit for each $i$ first and computing the limit of those limits afterwards. By recognizing that $\scI \times \scJ \cong \scJ \times \scI$, we can compute the limits stepwise in either order, which also proves the statements that limits commute with other limits. With these remarks out of the way, we now proceed with the proof.
	
	Suppose first that $\lim G$ exists, with projections $p_i : \lim G \to \lim F_i$ for each $i \in \scI$. I claim that $\lim G$ equipped with the maps $\pi_{i,j} \circ p_i : \lim G \to F_i(j) = F(i,j)$ for each $(i,j) \in \scI \times \scJ$ is a limit of $F$. First, we show that this is a cone over $F$. Suppose we have a map $(f,g) : (i,j) \to (i',j')$ in $\scI \times \scJ$. Then,
	\begin{align*}
	F(f,g) \circ (\pi_{i,j} \circ p_i)
		&= F(f,\id_{j'}) \circ F(\id_i,g) \circ \pi_{i,j} \circ p_i \\
		&= F(f,\id_{j'}) \circ F_i(g) \circ \pi_{i,j} \circ p_i \\
		&= F(f,\id_{j'}) \circ \pi_{i,j'} \circ p_i \\
		&= \pi_{i',j'} \circ G(f) \circ p_i \\
		&= \pi_{i',j'} \circ p_{i'}
	\end{align*}
	as desired. Lastly, we show it is a universal cone. Suppose we have an object $X \in \scC$ with maps $h_{i,j} : X \to F(i,j)$ for each $(i,j)$ such that $F(f,g) \circ h_{i,j} = h_{i',j'}$ for every $(f,g) : (i,j) \to (i',j')$. Notice that, for a fixed $i$ and any $g : j \to j'$, we have
	\[ F_i(g) \circ h_{i,j} = F(\id_i,g) \circ h_{i,j} = h_{i,j'} \]
	so that the collection of maps $\{h_{i,j}\}_{j \in \scJ}$ is a cone over $F_i$. Thus, we get a unique map $u_i : X \to \lim F_i$ with $h_{i,j} = \pi_{i,j} \circ u_i$. Then, note that for $f : i \to i'$, we have
	\[ \pi_{i',j} \circ G(f) \circ u_i = F(f,\id_j) \circ \pi_{i,j} \circ u_i = F(f,\id_j) \circ h_{i,j} = h_{i',j} \]
	By uniqueness, we conclude that $G(f) \circ u_i = u_{i'}$. In other words, the collection of maps $u_i$ forms a cone over $G$, and so we get a unique map $u : X \to \lim G$ such that $p_i \circ u = u_i$ for each $i$. Then,
	\[ \pi_{i,j} \circ p_i \circ u = \pi_{i,j} \circ u_i = h_{i,j} \]
	and so we've factored each $h_{i,j}$ through $u$ as needed. Finally, we need to see that $u$ is unique with this property. Suppose $u' : X \to \lim G$ is such that $\pi_{i,j} \circ p_i \circ u' = h_{i,j}$ for all $(i,j)$. The uniqueness of $u_i$ shows that $p_i \circ u' = u_i$, and the uniqueness of $u$ gives $u' = u$, completing the argument in this direction that $\lim G$ is a limit of $F$.
	
	Conversely, suppose now that $\lim F$ exists, with projections $q_{i,j} : \lim F \to F(i,j)$ for each $(i,j)$. Notice that for a fixed $i$ and any $g : j \to j'$, we have
	\[ F_i(g) \circ q_{i,j} = F(\id_i,g) \circ q_{i,j} = q_{i,j'} \]
	so that we have a cone over $F_i$, giving for each $i$ a unique map $v_i : \lim F \to \lim F_i$ satisfying $q_{i,j} = \pi_{i,j} \circ v_i$. I claim that $\lim F$, along with the maps $v_i$ is a limit of $G$. To see that it is a cone over $G$, note:
	\[ \pi_{i',j} \circ G(f) \circ v_i = F(f,\id_j) \circ \pi_{i,j} \circ v_i = F(f,\id_j) \circ q_{i,j} = q_{i',j} \]
	and so the uniqueness of $v_{i'}$ gives $v_{i'} = G(f) \circ v_i$. Next, we show it is a universal cone. Suppose we have an object $X \in \scC$ with maps $h_i : X \to G(i)$ for each $i$ such that $G(f) \circ h_i = h_{i'}$ for each $f : i \to i'$. Then, for any map $(f,g) : (i,j) \to (i',j')$:
	\begin{align*}
	F(f,g) \circ \pi_{i,j} \circ h_i
		&= F(\id_{i'},g) \circ F(f,\id_j) \circ \pi_{i,j} \circ h_i \\
		&= F_{i'}(g) \circ \pi_{i',j} \circ G(f) \circ h_i \\
		&= \pi_{i',j'} \circ h_{i'}
	\end{align*}
	so that the collection $\pi_{i,j} \circ h_i$ is a cone over $F$. So, there is a unique map $v : X \to \lim F$ such that $\pi_{i,j} \circ h_i = q_{i,j} \circ v$. Then,
	\[ \pi_{i,j} \circ v_i \circ v = q_{i,j} \circ v = \pi_{i,j} \circ h_i \]
	Since $\lim F_i$ is a limit with projections $\pi_{i,j}$, uniqueness gives that $v_i \circ v = h_i$, i.e. $v$ factors each $h_i$ through the corresponding $v_i$. Finally, we show $v$ is unique with this property; suppose that $v_i \circ v' = h_i$ for each $i$. Then
	\[ q_{i,j} \circ v' = \pi_{i,j} \circ v_i \circ v' = \pi_{i,j} \circ h_i \]
	and so the uniqueness of $v$ gives $v' = v$, completing the proof entirely.
\end{proof}
